# Gains and predictability of coverage sampling in nanomedicine formulation screening: a multi-dataset benchmark

Analysis code for the benchmark reported in the accompanying paper: the sampling-strategy × predictor × budget grid, and the statistical analyses behind its results.

This is a partial source release. The datasets are third-party public data and are not included; derived artefacts are archived separately (DOI in the paper). No support is provided.
